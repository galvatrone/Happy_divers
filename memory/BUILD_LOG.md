# Happy Divers — журнал сборки 3D-мира

Читать этот файл вместо перечитывания кода. Обновляется после каждого этапа.

## Идея
Главный экран: камера над водой, смотрит с моря на пляж. Прокрутка = погружение:
лагуна → коралловый сад → стена рифа → пещера → сумеречная зона (бронирование).
В каждой зоне своё освещение и туман. Карточки по пути рассказывают о дайв-центре.

## Как запустить
- `npm run dev` → http://localhost:5173
- `npm run build` → `dist/`
- Отладка: `?p=0.4` в адресе фиксирует точку погружения (0 = берег, 1 = конец), загрузочный экран пропускается.
- Прод: https://happy-divers.vercel.app

## Карта мира (координаты)
- Уровень моря `y = 0`. Берег при `z < -45`, остров ±130 по `x`. Море глубже к `+z`.
- Лагуна `z -45…30` (до −9 м) → коралловый сад `z 30…100` (−9…−17) → обрыв-стена `z 105…117` (до −33)
  → скальный массив с пещерой `z 147…187` → сумеречная зона `z 190…250` (−36…−40).
- Камера: 23 точки сплайна в `src/store/cameraCurve.js`. Старт `(0, 1.5, 24)` смотрит на пляж,
  ныряет, разворачивается в лагуне и уходит в море.

## Ключевые решения
- Мир процедурный, без GLB (тяжёлые `assets/model/*.glb` и `assets/frames` сценой не используются).
- Рельеф — одна функция `terrainHeight(x, z)`; под путём камеры вырезан канал (в массиве он становится пещерой, сверху — плита `Cave.jsx`).
- Вода: один шейдер, сверху отражение неба + блики + пена у берега (глубина из запечённой карты высот), снизу окно Снеллиуса.
- Каустика встроена в материалы (`patchUnderwater`), а не отдельными плоскостями.
- Производительность (встроенная AMD-графика): Lambert вместо PBR, без MSAA, рельеф тайлами,
  инстансы полосами по `z` + отсечение дальше 105 м (`cullables` в `Rig.jsx`), DPR сам падает при низком FPS.
- Текстуры Poly Haven (CC0, 1k): `rock_face_03`, `coral_stone_wall`, `palm_tree_bark`, `brown_planks_05`, `thatch_roof_angled` в `assets/textures/`.
- Регион — Красное море (так в последних правках и телефоне +20). В git-истории было «Mediterranean» — уточнить у владельца.

## Как проверять без браузера
Headless-скриншот точки погружения: `chromium --headless=new --window-size=1280,720 --virtual-time-budget=2500 --screenshot=out.png "http://localhost:5173/?p=0.4"`.
На этой машине (встроенная AMD Radeon) один кадр снимается 20–100 с, особенно если сайт открыт во вкладке.
